Semana 1: Apache Maven

La actividad consiste en implementar aplicaciones utilizando Apache Maven y documentar cada uno de los proyectos formulados.

Enunciado 01: Venta de Camisas

  • Enunciado del proyecto: Una tienda ha puesto en oferta la venta de camisas ofreciendo un descuento por temporada de verano denominado 7% + 7%. Se calcula el importe de compra, los descuentos sucesivos y el total a pagar.
  • Código de la aplicación: 
    import java.util.Scanner;

public class VentaCamisas {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese el precio de la camisa: ");
        double precio = scanner.nextDouble();
        
        System.out.print("Ingrese la cantidad adquirida: ");
        int cantidad = scanner.nextInt();
        
        double importeCompra = precio * cantidad;
        double primerDescuento = importeCompra * 0.07;
        double segundoDescuento = (importeCompra - primerDescuento) * 0.07;
        double descuentoTotal = primerDescuento + segundoDescuento;
        double importePagar = importeCompra - descuentoTotal;
        
        System.out.println("\n--- TICKET DE VENTA ---");
        System.out.printf("Importe de la compra: S/ %.2f\n", importeCompra);
        System.out.printf("Primer descuento (7%%): S/ %.2f\n", primerDescuento);
        System.out.printf("Segundo descuento (7%%): S/ %.2f\n", segundoDescuento);
        System.out.printf("Descuento total: S/ %.2f\n", descuentoTotal);
        System.out.printf("Importe a pagar: S/ %.2f\n", importePagar);
        
        scanner.close();
    }
}

Actividad 01: Planilla de Vendedor

  • Enunciado del proyecto: Cálculo de la boleta de un vendedor con un sueldo básico de S/. 350.75, una comisión del 5% sobre ventas y un descuento de ley del 15% sobre el sueldo bruto.
  • Código de la aplicación: 
    import java.util.Scanner;

public class PlanillaVendedor {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese el importe total vendido en el mes: S/ ");
        double totalVendido = scanner.nextDouble();
        
        double sueldoBasico = 350.75;
        double comision = totalVendido * 0.05;
        double sueldoBruto = sueldoBasico + comision;
        double descuento = sueldoBruto * 0.15;
        double sueldoNeto = sueldoBruto - descuento;
        
        System.out.println("\n--- BOLETA DE PAGO ---");
        System.out.printf("Sueldo Básico: S/ %.2f\n", sueldoBasico);
        System.out.printf("Comisión (5%%): S/ %.2f\n", comision);
        System.out.printf("Sueldo Bruto: S/ %.2f\n", sueldoBruto);
        System.out.printf("Descuento de Ley (15%%): S/ %.2f\n", descuento);
        System.out.printf("Sueldo Neto a Pagar: S/ %.2f\n", sueldoNeto);
        
        scanner.close();
    }
}

Actividad 04: Sueldo y Bonificación por Categoría e Hijos

  • Enunciado del proyecto: Cálculo del sueldo neto aplicando una tarifa por hora según categoría (A o B), una bonificación basada en el número de hijos y un descuento porcentual basado en el sueldo bruto.
  • Código de la aplicación: 
    import java.util.Scanner;

public class SueldoCategorias {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese la categoría del empleado (A o B): ");
        String categoria = scanner.next().toUpperCase();
        System.out.print("Ingrese las horas trabajadas: ");
        double horas = scanner.nextDouble();
        System.out.print("Ingrese la cantidad de hijos: ");
        int hijos = scanner.nextInt();
        
        // Determinar tarifa por hora
        double tarifa = (categoria.equals("A")) ? 45.0 : 37.5;
        double sueldoBasico = horas * tarifa;
        
        // Determinar bonificación por hijos
        double bonificacion = (hijos <= 3) ? (hijos * 40.5) : (hijos * 35.0);
        double sueldoBruto = sueldoBasico + bonificacion;
        
        // Determinar descuento
        double porcentajeDescuento = (sueldoBruto >= 3500) ? 0.135 : 0.10;
        double descuento = sueldoBruto * porcentajeDescuento;
        double sueldoNeto = sueldoBruto - descuento;
        
        System.out.println("\n--- BOLETA DE PAGO DEL EMPLEADO ---");
        System.out.printf("Sueldo Básico: S/ %.2f\n", sueldoBasico);
        System.out.printf("Bonificación por hijos: S/ %.2f\n", bonificacion);
        System.out.printf("Sueldo Bruto: S/ %.2f\n", sueldoBruto);
        System.out.printf("Descuento aplicado: S/ %.2f\n", descuento);
        System.out.printf("Sueldo Neto a Pagar: S/ %.2f\n", sueldoNeto);
        
        scanner.close();
    }
}

Semana 3: Estructuras Condicionales y Obsequios

En esta semana se desarrollan programas utilizando estructuras condicionales (if/else) para la toma de decisiones, aplicando descuentos dinámicos y bonificaciones en forma de obsequios según montos y cantidades de compra.

Actividad 01: Venta de Docenas con Descuento y Obsequio

  • Enunciado del proyecto: Cálculo del descuento por cantidad de docenas compradas (>= 10 docenas aplica 20%, sino 10%). Además, se calculan lapiceros de obsequio si el importe a pagar es mayor o igual a S/. 200 (2 lapiceros por cada docena).
  • Código de la aplicación: 
    import java.util.Scanner;

public class VentaProducto {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese el precio de la docena: S/ ");
        double precioDocena = scanner.nextDouble();
        System.out.print("Ingrese la cantidad de docenas adquiridas: ");
        int cantidadDocenas = scanner.nextInt();
        
        // Cálculos base
        double importeCompra = precioDocena * cantidadDocenas;
        
        // Condicional para porcentaje de descuento
        double porcentajeDescuento = (cantidadDocenas >= 10) ? 0.20 : 0.10;
        double importeDescuento = importeCompra * porcentajeDescuento;
        double importePagar = importeCompra - importeDescuento;
        
        // Condicional para obsequio de lapiceros
        int lapiceros = (importePagar >= 200) ? (2 * cantidadDocenas) : 0;
        
        System.out.println("\n--- DETALLE DE COMPRA ---");
        System.out.printf("Importe de la compra: S/ %.2f\n", importeCompra);
        System.out.printf("Importe del descuento: S/ %.2f\n", importeDescuento);
        System.out.printf("Importe a pagar: S/ %.2f\n", importePagar);
        System.out.println("Lapiceros de obsequio: " + lapiceros);
        
        scanner.close();
    }
}

Actividad 02: Venta de Pasajes Lima - Huancayo

  • Enunciado del proyecto: Una empresa de transportes cubre la ruta Lima - Huancayo. El pasaje cuesta S/. 37.5 para los turnos Mañana y Noche. Se aplica un descuento del 8% si se compran 15 o más pasajes, y 5% si son menos. Además, se regalan 2 caramelos por boleto si el pago supera los S/. 200.
  • Código de la aplicación: 
    import java.util.Scanner;

public class VentaPasajes {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Ingrese el turno (Mañana/Noche): ");
        String turno = scanner.next();
        System.out.print("Ingrese la cantidad de pasajes a comprar: ");
        int cantidadPasajes = scanner.nextInt();
        
        // Precio único para ambos turnos
        double precioPasaje = 37.5; 
        double importeCompra = precioPasaje * cantidadPasajes;
        
        // Condicional para porcentaje de descuento
        double porcentajeDescuento = (cantidadPasajes >= 15) ? 0.08 : 0.05;
        double importeDescuento = importeCompra * porcentajeDescuento;
        double importePagar = importeCompra - importeDescuento;
        
        // Condicional para obsequio de caramelos
        int caramelos = (importePagar > 200) ? (2 * cantidadPasajes) : 0;
        
        System.out.println("\n--- DETALLE DE VENTA DE PASAJES ---");
        System.out.println("Turno elegido: " + turno);
        System.out.printf("Importe de la compra: S/ %.2f\n", importeCompra);
        System.out.printf("Importe del descuento: S/ %.2f\n", importeDescuento);
        System.out.printf("Importe a pagar: S/ %.2f\n", importePagar);
        System.out.println("Caramelos de obsequio: " + caramelos);
        
        scanner.close();
    }
}
